# Matices - Consultoría Integral

Rediseño y desarrollo de la plataforma web corporativa de Matices Consultoría Integral, optimizada para generación de prospectos y venta consultiva B2B mediante arquitectura de alto rendimiento.

## Características del Proyecto
- Estructuración modular estática.
- Configuración de estilos global integrada mediante la directiva `@theme` de Tailwind CSS v4.
- Formulario estructurado de calificación comercial con validación en cliente y soporte nativo para notificaciones contextuales.
- Componentes de interfaz adaptables de alta gama (carrusel infinito interactivo y galería de evidencias tipo masonry con lightbox integrado).
